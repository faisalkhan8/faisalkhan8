## Selected Projects

### Research & Semantic Technologies

**[OGE-Fashion — Ontology-Guided Explainable Recommendation Framework](https://github.com/faisalkhan8/OGE-Fashion)**

An ongoing research extension of my undergraduate final-year project, exploring ontology-guided and explainable recommendations across fashion and beauty domains. The repository includes an OWL/Turtle ontology, source-aligned vocabulary work, SPARQL competency queries, SHACL validation, reasoning checks, and a reproducible synthetic benchmark.

*Research status: ongoing. Current synthetic experiments and validation demonstrate implementation behaviour; they do not establish real-user recommendation quality.*

### Machine Learning & Computer Vision

**[Vehicle Detection and Speed Estimation](https://github.com/faisalkhan8/Car-Detection-and-Speed-Calculation-with-YOLOv8-Sort-and-OpenCV)**

A computer-vision project using YOLOv8, SORT, and OpenCV to detect and track vehicles and estimate their speed from video.

**[Applied Machine Learning Assignment](https://github.com/faisalkhan8/AMLS_assignment20_21)**

Supervised learning coursework involving facial-attribute classification, including CNN-based image classification and an SVM-based approach.

### Data Engineering

**[Federal Audit Clearinghouse Data Integration Pipeline](https://github.com/faisalkhan8/csv_merge_project)**

A Python pipeline for retrieving and merging Federal Audit Clearinghouse datasets, with API integration, schema validation, retry handling, and DuckDB-based data processing.

### AI & Full-Stack Applications

**[Pet Calorie Calculator](https://petcalorie.com/)**
